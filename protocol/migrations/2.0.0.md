# Protocol migration — 2.0.0

Protocol 1.0.0 shipped 166 rules. The source document Prumo was ported from has 183. This release restores the 17 missing rules, resolves one normative contradiction, and adds Section 20 for the protocol's own integrity. Total: 201 rules. No id was recycled.

## Restored (present in the source protocol, missing from 1.0.0)

- PRU-29 — no gold-plating. Out-of-scope observations become suggestions, never silent diffs.
- PRU-152, PRU-153, PRU-154, PRU-155, PRU-156, PRU-157, PRU-158, PRU-159 — Section 15, honest verdict: mandatory verdict first, bad said as bad, alternatives with every negative verdict, closed list of flattery, change of mind only on a new fact, honest grade of the agent's own delivery, no claimed verification that did not happen, single evidence-based correction of the user.
- PRU-240, PRU-241, PRU-242, PRU-243, PRU-244, PRU-245, PRU-246, PRU-247 — Section 19, hypothesis-driven debugging: reproduce, read the whole error, written hypothesis with one variable per experiment, bisect, fix the cause, ship the failing test, environment differences are the main hypothesis, root cause recorded.

## Changed semantics

- PRU-20 — old: "No comments", with a three-item exception list that contradicted PRU-177 and PRU-182. New: "No decorative comments"; the only allowed comments are the PRU-177 closed list and PRU-182 public API documentation. Reason: remove the normative contradiction (PRU-267).
- PRU-91 — inspection item 4 now reads "every comment you introduced outside the PRU-177 and PRU-182 exceptions".
- PRU-150 — gate item 4 now reads "no new comment outside the PRU-177 and PRU-182 exceptions".
- PRU-151 — the final report ends with the honest grade of the delivery (PRU-157) and suggestions come last, marked as suggestions.
- PRU-100 — MapSource.md gains schema 2: front matter and nine mandatory headings in a fixed order, including Root causes and Project commands.
- PRU-111 — a suspicion item is structured and its severity comes from the closed set critical, high, medium, low.

## Changed wording, same intent

- PRU-01 — adds the PowerShell fallback and prefers the session's file-search tool.
- PRU-16 — points at Section 19.
- PRU-31 — names the decorative agreement phrases and points at Section 15.
- PRU-33 — adds: "should work" does not exist.
- PRU-34 — retitled "Direct is not rude to the person"; hardness aims at the work, never the person.
- PRU-35 — the opinion is stated before executing with verdict, reason and alternative; a reaffirmed decision is recorded in MapSource.md and the final report still declares the risk.
- PRU-41 — names the question tools of other harnesses and plain text as fallback.

## Added

- PRU-250 to PRU-267 — Section 20, protocol integrity and runtime: single source, integrity before distribution, context budget, deterministic routing, presence is not activation, foreign files preserved, transactional installation, reversibility, fail-open but not silent hooks, inspectable state, bounded MapSource, enforcement is not marketing, adapters prove capability, artifact identity, a change requires an eval, external metadata is data, foreign configuration wins, contradictions fail the build. The section also fixes rule precedence.
